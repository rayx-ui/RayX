# components: state

## Purpose And Usage

Route work on RayX's components, its theme document and keys, and the gallery.

## Current Technical Shape

- `theme.json`: RayX's NSH theme document, generated by the `rayx-components` skill's
  `theme_codegen.py` from the DTCG export (710 tokens: kinds, paths in WEB code syntax, docs;
  Light/Dark as `cssVars` light/dark; modifiers `accent`, `density`, `os`, defaults cyan, desktop,
  windows; nsh-base roles). No theme type since the 2026-11-16 move (epic `ts-app-builder`,
  sprint `s2-theme`); the move renamed no token.
- `src/theme/`: `keys` (`theme_keys!("theme.json")`: a `TokenKey` per token, and the modifier
  enums in `keys::modifiers`), `DOCUMENT`, `value(key)`, `ComponentSize` and the hand-written
  lookups `SizeKeys`/`LevelKeys`/`TextStyleKeys`/`RoleKeys` (`text_style_keys!`),
  `bind_text_style`, `weight`.
- `src/macros.rs`: `color!` (hex checked at compile time) only; custom themes are NSH's
  (`update_tokens`, theme files, `ThemeScope`).
- `src/button.rs`: `Button` on nsh-base's `Button`, its look one `Look` memo of keys.
- `register(registry)` adds the theme document and the components to an app's UI set. RayX sets
  no modifier itself: the app does (a `ThemeService` may later).
- `examples/gallery`: a mixed NSH app (`nsh.json` `"rust": "native"`), its crate `rayx-gallery`
  (a workspace member, `release = false`) registering the library and `Glyph`; its toolbar picks
  the accent and density with `setModifier`.
