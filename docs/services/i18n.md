# I18n

Translations with MessageFormat 2 messages, and numbers, dates and plurals formatted for the user's locale.
`I18nService` wraps [dXn.I18n](https://github.com/dXnSix/dXn.I18n)'s `Translator` (messages, bundles, fallback lookup)
and formats with [dXn.Intl](https://github.com/dXnSix/dXn.Intl) (ICU4X), the same on every platform.

## Register

```rust
builder.add_i18n(|options| {
    options.default_language("en").fallback_language("de");
})
```

`add_i18n` registers the [asset service](assets.md) too. `I18nService` is a startup service that initializes after it.

## Configure

Options bind from `RayX:Services:I18N`, then the closure changes them: the default language, the fallback languages,
the resources path (`locales`), the default namespace, automatic loading of the asset catalog's translations, following
the platform's languages, the missing-message policy and bidi isolation.

```json
{ "RayX": { "Services": { "I18N": { "defaultLanguage": "en", "fallbackLanguages": ["de"] } } } }
```

## Translations

Translations are assets: `locales/<language>.json`, or `locales/<language>/<namespace>.json`, whose ids a namespace
other than the default one prefixes (`checkout.title`). Every language loads at startup, so changing the language is
immediate.

## Use

```rust
let i18n = services.required_service::<I18nService>()?;
let title = i18n.t("title");
let cart = i18n.format("cart", &Args::new().with("n", 3)); // "3 items"
i18n.set_language("de")?;
```

- The language follows the platform service's preferred languages and clock (the best of the app's languages for the
  user's list, with the user's region and `-u-hc-` hour cycle) until the app picks one with `set_language`.
- Messages are looked up through the language's parents, the fallback languages and the default one.
- `locale()`, `language()`, `available_languages()`, `direction()`, `plural_category(n)`; `subscribe` hears every
  change of language or messages.

## TSX

```tsx
const i18n = I18n.of(app);
i18n.t("cart", { n: 3 });
i18n.setLanguage("de");
i18n.onChange((locale) => refresh());
```
